# Cap Laoban Investments

Статический сайт с аналитикой акций: https://caplaoban-tech.github.io

## Структура
- `index.html` — главная: список компаний и лента новостей.
- `nckl/` — страница компании с калькулятором «что если».
- `data/` — данные: `companies.json` (список), `news.json` (лента), `<тикер>.json` (цифры, модель калькулятора, риски, триггеры).
- `assets/` — стиль, логотип, иконки.

## Инструменты
- `templates/company/` — шаблон страницы компании, формат данных (`SCHEMA.md`) и демо-пример (`/templates/company/`).
- `tools/new_company.py ТИКЕР "Название" "Сектор"` — заготовка страницы и данных новой компании.
- `tools/check_site.py --fix` — проверка перед публикацией: пустые страницы, битые ссылки, входы без источника и даты, рендер на телефоне.
- `CLAUDE.md` и `.claude/skills/` — правила сайта и порядок сборки разбора компании и разбора отчёта об оценке.

## Как обновлять
Цифры живут в `data/*.json`. Новый разбор = новый или обновлённый JSON; страницы читают его сами.
Метки: [А] — из отчётности, [Б] — расчёт, [В] — внешний источник или оценка.
