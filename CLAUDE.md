# Cap Laoban — правила сайта

Статический сайт на GitHub Pages (ветка `main`, корень). Без сборщиков и фреймворков: HTML + `assets/style.css` + данные в `data/*.json`.

## Типы страниц
| Тип | Где | Как делается |
|---|---|---|
| Разбор компании | `<тикер>/index.html` + `data/<тикер>.json` | Навык `.claude/skills/publish-company`. Страница — копия `templates/company/index.html`, всё содержание в JSON (формат: `templates/company/SCHEMA.md`). |
| Разбор отчёта об оценке | `<slug>/index.html` (самодостаточная) | Навык `.claude/skills/publish-valuation-review`. Образец — `res/`. |
| Особая страница компании | `<тикер>/index.html` со своим калькулятором | Как `nckl/`: только когда модели не хватает линейных чувствительностей. Данные всё равно в JSON. |

Главная `index.html` рисует список из `data/companies.json` и ленту из `data/news.json`. Строка с `"draft": true` на главной не видна; `"kind": "report"` — разбор отчёта об оценке.

## Содержательные правила (обязательны)
1. **Структура оценки видна читателю**: из каких денежных потоков (свой бизнес, ассоциаты, …) и поправок складывается стоимость; у каждой части — расчёт и источник. Никаких «справедливая цена = X» без разложения.
2. **У каждого рыночного входа** (сырьё, курс, ставка, цена акции) — источник и дата. Указать, с каким лагом цена доходит до компании.
3. **Метки достоверности** у каждой цифры: [А] из отчётности, [Б] расчёт, [В] внешний источник или оценка.
4. **Шкала справедливой цены считается той же моделью** (id сценариев, не ручные числа).
5. **Сравнение с аналогами**: минимум 2–3 прямых конкурента, не только P/E — выручка и её структура, долг, дивиденды, запасы/качество активов.
6. **Риски включают форензик и корпоративное управление** (изъятие стоимости контролёром, сделки со связанными сторонами, разрыв прибыли и денежного потока).
7. **Термины объясняются**: всё, что не знает непрофессионал, — в `glossary` и сноской `{{ключ|слово}}`.
8. Заголовок — тезис одной фразой, а не название компании. Тон спокойный, без рекламы.
9. На сайте **нет ссылок на claude.ai / anthropic** и упоминаний, где сделан разбор.
10. Страница работает на телефоне шириной 400 px без горизонтальной прокрутки.

## Перед каждым push
```
python3 tools/check_site.py --fix --shots <папка-для-скриншотов>
```
0 ошибок — обязательное условие. Посмотреть скриншоты своими глазами. Проверка ловит: пустые/обрезанные страницы, битые ссылки, входы без источника и даты, потоки без расчёта, ссылки на claude.ai, NaN на странице, горизонтальную прокрутку, расхождение главной с данными.
