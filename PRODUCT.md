# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users
Владелец портфеля и его близкий круг (друзья, партнёры по инвестициям). Читают с телефона, часто по ссылке из Telegram, принимают решения по своему портфелю акций Азии (Индонезия IDX, Китай A/H, Гонконг). Не профессиональные аналитики, но вникают в цифры.

## Product Purpose
Сайт Cap Laoban — рабочий инструмент решений по акциям: разборы компаний на отчётности, оценка по частям с калькулятором «что если», риск-гейт (форензик, корпоративное управление), скрининги. Успех — читатель за несколько минут видит, сколько стоит компания, откуда каждая цифра и что сломает тезис.

## Positioning
Каждая цифра с источником и меткой достоверности [А] отчётность / [Б] расчёт / [В] внешний источник; оценка раскладывается по денежным потокам, а не «справедливая цена = X»; сверки компаний с партнёрами на других биржах (Китай ↔ Индонезия).

## Operating Context
Статический сайт на GitHub Pages (caplaoban-tech.github.io), без сборщиков: HTML + assets/style.css + данные в data/*.json. Разборы готовятся вне сайта (стандарты анализа на Google Drive) и упаковываются в JSON. Перед публикацией обязательна проверка tools/check_site.py (0 ошибок, ширина телефона 400 px). Рыночные данные обновляются GitHub Actions по рабочим дням.

## Capabilities and Constraints
- Типы страниц: разбор компании (шаблон templates/company), особая страница с калькулятором (nckl/), разбор отчёта об оценке (res/), скрининг (ah/ — A+H акции, P/E H < 15).
- Правила CLAUDE.md репозитория обязательны: спокойный тон, без рекламы, термины в словаре, заголовок — тезис, нет ссылок на claude.ai/anthropic, работа на телефоне 400 px без горизонтальной прокрутки.
- Язык — русский.

## Evidence on Hand
Данные разборов в data/*.json; скрининг A+H — ~/work/china-reports/ah-screen/ (ah_triage_2026-10-23.csv, ah_explainer_ru.md). Отзывов, клиентов, цен, лицензий нет и не придумывать.

## Product Principles
1. Цифра без источника и даты не публикуется.
2. Показывать механизм, а не вывод: из чего складывается стоимость и что её ломает.
3. Риски и ловушки видны так же явно, как возможности.
4. Телефон — основной экран.
